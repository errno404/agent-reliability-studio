## Web gotchas (hard-won)
- Web needs **Node >= 22** (Tailwind 4.3 ESM + Turbopack hang on Node 20). `.nvmrc` = 22. Use `export PATH=$HOME/.nvm/versions/node/v22.23.4/bin:$PATH`.
- next.config pins `outputFileTracingRoot`/`turbopack.root` to the repo: a stray `~/package-lock.json` made Next crawl $HOME and hang.
- Browser -> API goes through a RUNTIME proxy route handler (`app/api/[...path]/route.ts`, reads `API_URL` per request). `rewrites()` bake the URL at build time: never use them.
- Dev server must be opened via `localhost` (allowedDevOrigins set for 127.0.0.1 too). npm needs `legacy-peer-deps` (.npmrc); TS pinned to 5.x (openapi-typescript); TanStack Table v8.
- Desktop is iCloud-synced: conflict copies like `node_modules 2` appear; they are gitignored/eslint-ignored; delete them.
- e2e: `bash scripts/e2e_api.sh` (seeded API on 8100) + `next start -p 3100`; `npx playwright test` (uses system Chrome).
